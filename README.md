אפליקציית ווב אינטראקטיבית המייצרת פסקאות מידע מעשירות על שפת JavaScript בהתאם לכמות המבוקשת על ידי המשתמש. הפרויקט מעוצב בערכת נושא כהה המבוססת על צבעי המותג של JavaScript (שחור וצהוב).

## מה נלמד בפרויקט?
* **טיפול באירועי טפסים:** מניעת ברירת המחדל של שליחת טופס באמצעות `e.preventDefault()`.
* **מתודות מערכים (Array Methods):** שימוש ב-`slice()` לחיתוך מספר האלמנטים המבוקש, ב-`map()` לעטיפת כל פסקה בתגית HTML, וב-`join()` לאיחוד למחרוזת אחת.
* **המרת טיפוסים ואימות:** שימוש ב-`parseInt()` וב-`isNaN()` לבדיקת תקינות הקלט שהזין המשתמש.
* **הזרקת תוכן ל-DOM:** עדכון דינמי של תוכן הדף באמצעות `innerHTML`.
* **עיצוב מודרני ב-CSS:** שימוש ב-Flexbox, משתני עיצוב (`:root`), ואנימציית `fadeIn` חלקה בעת יצירת הפסקאות.

## מבנה הקבצים
* `index.html` – מבנה הדף, שדה הקלט (Input), כפתור ההפקה ומכל התוצאות.
* `styles.css` – סגנונות עיצוב כהים, פונטים, צבעי JS ואנימציית כניסה.
* `app.js` – מאגר פסקאות המידע על JavaScript והלוגיקה להפקתן למסך.
